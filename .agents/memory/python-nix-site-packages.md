---
name: Python Nix site-packages
description: Replit's Python runtime may not automatically see packages installed through Nix.
---

**Rule:** Build `PYTHONPATH` from the Nix store's `site-packages` directory matching the active Python version before launching Flask.

**Why:** In this workspace, `.pythonlibs` targeted a different Python version and `pip --user` was unavailable; Nix packages installed successfully but were not importable until the path was added.

**How to apply:** Keep local Flask workflow and deployment commands using the shared wrapper or an equivalent version-aware `PYTHONPATH` setup.
